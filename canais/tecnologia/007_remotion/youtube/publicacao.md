E se o vídeo fosse código? Com o Remotion, cada quadro é um componente React: você troca um dado e sai um vídeo novo. Neste vídeo você vê como ele funciona, como começar com um comando só, como gerar mil vídeos personalizados a partir de uma planilha, como usar com agentes de IA como o Claude Code, e o detalhe importante da licença.

📌 O que você vai aprender:
✅ A ideia do Remotion: um vídeo é uma sequência de quadros desenhados com React
✅ Composição: largura, altura, fps e duração em quadros
✅ Animar com useCurrentFrame, interpolate, spring e Sequence
✅ Começar com npx create-video@latest e o Remotion Studio
✅ Renderizar: Studio, terminal, servidor, AWS Lambda e GitHub Actions
✅ Vídeos a partir de dados: um modelo, mil renderizações
✅ Agent Skills: Remotion com Claude Code, Codex e Cursor
