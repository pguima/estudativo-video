## Descrição
y = 1 + 2 · cos(2x) parece assustador, mas cada número ali tem uma tarefa só. Nesta aula, você vê o que cada letra de y = a + b · cos(cx) faz com a onda: o b estica a altura (a amplitude), o a empurra a onda inteira para cima ou para baixo (a linha do meio sobe para y = a) e o c aperta a onda, dividindo o período: em cos(2x), cabem duas ondas onde antes cabia uma, e o período cai de 2π para π. Juntando tudo, você lê em y = 1 + 2 cos(2x) o máximo 3, o mínimo −1, o período π e a imagem de −1 a 3. Também vê o erro de multiplicar o período pelo c e leva um atalho de prova com três contas, inclusive quando o b ou o c vêm negativos. Tudo vale igual para o seno. Serve para quem está voltando a estudar e para quem quer fechar a base antes de ENEM, Fuvest, Unicamp, Unesp e UERJ.
