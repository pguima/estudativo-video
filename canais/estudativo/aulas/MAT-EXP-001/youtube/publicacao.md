## Descrição
Dobre uma folha de papel ao meio dez vezes e ela fica 1.024 vezes mais grossa. Essa conta é uma função exponencial: o x mora no expoente. Nesta aula, você monta a tabela de 2ˣ e de (1/2)ˣ, desenha os dois gráficos, descobre quem decide se a curva sobe ou desce e entende por que a base tem de ser positiva e diferente de 1. No fim, leva o atalho do espelho para montar uma tabela a partir da outra. Serve para quem está voltando a estudar e para ENEM, Fuvest, Unicamp, Unesp e UERJ.

📌 O que você vai aprender
✅ A lei f(x) = 2ˣ: a base fica fixa e o expoente é a entrada
✅ A tabela de 2ˣ de −2 até 3: 1/4, 1/2, 1, 2, 4, 8
✅ O gráfico crescente: cada passo para a direita dobra a altura
✅ O gráfico de (1/2)ˣ, decrescente: cada passo corta a altura pela metade
✅ Os dois passam por (0, 1) e nunca encostam no eixo x
✅ Base maior que 1 sobe; base entre 0 e 1 desce
✅ Por que a base não pode ser 1, 0 nem negativa
✅ O erro de achar que 2⁻¹ dá −2 (dá 1/2)
✅ O atalho do espelho: (1/2)ˣ = 2⁻ˣ, só para bases inversas
