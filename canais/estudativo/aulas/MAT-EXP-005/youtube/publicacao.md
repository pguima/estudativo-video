## Descrição
Muita gente resolve (1/2)ˣ > 8 igualando as bases e escreve x > −3. Mas teste x = 0: (1/2)⁰ dá 1, que não é maior que 8, e mesmo assim 0 é maior que −3. Alguma coisa deu errado. Nesta aula, você resolve inequações com o x no expoente e descobre quando o sinal vira: com base maior que 1, o sinal se mantém; com base entre 0 e 1, o sinal vira. Você vê isso no gráfico, marca a solução na reta com bolinha aberta ou fechada e leva um atalho de prova. Serve para quem está voltando a estudar e para ENEM, Fuvest, Unicamp, Unesp e UERJ.

📌 O que você vai aprender
✅ 2ˣ > 8 vira 2ˣ > 2³ e, com base 2, o sinal fica: x > 3
✅ A bolinha aberta no 3, porque 2³ dá 8, que não é maior que 8
✅ (1/2)ˣ > 8 vira (1/2)ˣ > (1/2)⁻³ e, com base 1/2, o sinal vira: x < −3
✅ Por que a curva que desce vira o sinal, com o teste x = −4
✅ A regra: base maior que 1 mantém, base entre 0 e 1 vira
✅ O erro oposto: virar o sinal só porque apareceu um expoente negativo
✅ O atalho: troque 1/2 por 2⁻¹ e deixe o menos do expoente virar o sinal
