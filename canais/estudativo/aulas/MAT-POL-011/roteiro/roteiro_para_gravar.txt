O ponto xis dois, ípsilon três, refletido no eixo ípsilon. Muita gente responde xis dois, ípsilon menos três. Errado. Ele vai para xis menos dois, ípsilon três.

Até o fim desta aula, você prevê onde uma figura vai parar depois de espelhar, girar ou deslizar, e leva um atalho de prova.

Para acompanhar, você precisa de duas coisas: o plano cartesiano, primeiro o corredor, que é o xis, depois o elevador, que é o ípsilon; e o eixo de simetria, que funciona como um espelho. Se faltar alguma, procure no canal.

São três movimentos. Em todos, a figura não muda de forma nem de tamanho: só de lugar ou de posição. Vamos usar uma bandeirinha na malha, com o alto do mastro em xis dois, ípsilon três.

Translação é deslizar a figura, sem girar. Todos os pontos andam o mesmo tanto, na mesma direção. Deslize a bandeira quatro para a direita e dois para baixo.

No corredor, dois mais quatro dá seis. No elevador, três menos dois dá um. O alto do mastro vai para xis seis, ípsilon um. E a bandeira continua do mesmo jeito: só mudou de lugar.

Reflexão é o espelho. Cada ponto vai para o outro lado do eixo, na mesma distância, por um caminho que cruza o eixo em ângulo reto. É a mesma ideia do eixo de simetria.

Reflita no eixo ípsilon, o eixo em pé. O alto do mastro está dois passos à direita dele. Vai para dois passos à esquerda, na mesma altura: xis menos dois, ípsilon três. E a bandeira fica espelhada: o pano, que apontava para a direita, agora aponta para a esquerda.

No eixo xis, o deitado, é o contrário: o ponto troca de cima para baixo. Xis dois, ípsilon três, vai para xis dois, ípsilon menos três.

Rotação é girar a figura em volta de um ponto, o centro, como o ponteiro gira em volta do meio do relógio. Vamos girar noventa graus, um quarto de volta, ao contrário do relógio, o mesmo sentido da contagem dos quadrantes, com centro na origem.

Olhe o caminho da origem até o alto do mastro: dois passos para a direita, depois três para cima. Quando a figura gira, o caminho gira junto. Para a direita vira para cima. Para cima vira para a esquerda.

O caminho novo é dois passos para cima e três para a esquerda. O ponto vai para xis menos três, ípsilon dois. A bandeira fica deitada, mas não espelhada.

Como saber se foi reflexão ou rotação? Rotação é girar a folha sobre a mesa. Reflexão é virar a folha do avesso. Se a figura só se encaixa na outra virando do avesso, foi reflexão.

O erro mais comum é o do começo: refletir no eixo ípsilon e trocar o sinal do ípsilon. Mas o eixo ípsilon fica em pé. Um espelho em pé troca a direita com a esquerda, e quem diz direita ou esquerda é o xis. Refletiu no eixo ípsilon, muda o sinal do xis.

Agora o atalho prometido, para girar noventa graus ao contrário do relógio, em volta da origem: troque os números de lugar e mude o sinal do que ficou na frente. Xis dois, ípsilon três. A troca dá três e dois. Mudando o sinal do primeiro, xis menos três, ípsilon dois.

Funciona porque o passo para a direita vira passo para cima, e o passo para cima vira passo para a esquerda, que é negativo. No sentido do relógio, é o contrário: o passo para a direita vira passo para baixo, e o passo para cima vira passo para a direita. Troque os números e mude o sinal do que ficou atrás: xis dois, ípsilon três, vai para xis três, ípsilon menos dois. Não compensa se o centro não for a origem. Aí, gire o caminho na malha, passo a passo.

Vamos lá. O eixo xis está deitado, então o ponto troca de cima para baixo: muda o sinal do ípsilon. Fica xis quatro, ípsilon menos um.

No giro, pelo atalho: a troca dá um e quatro. Muda o sinal do primeiro: xis menos um, ípsilon quatro. Pelo caminho: quatro passos para a direita viram quatro para cima, e um passo para cima vira um para a esquerda. Bateu.

Resumindo: translação desliza, reflexão espelha e rotação gira em volta de um centro.
