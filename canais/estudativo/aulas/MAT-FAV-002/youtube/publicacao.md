## Descrição
Menos sete e sete são números diferentes, mas cada um está a sete passos do zero. Essa distância é o módulo. Nesta aula, você calcula o módulo, entende por que ele é uma função definida por partes, desenha o V de y = |x|, leva o V para qualquer lugar do plano com y = |x − 2| + 1 e rebate para cima a parte de baixo da parábola y = |x² − 4|. No fim, um atalho de prova para achar o vértice sem desenhar nada. Serve para quem está voltando a estudar e para quem quer fechar a base antes de ENEM, Fuvest, Unicamp e UERJ.

📌 O que você vai aprender
✅ Módulo é distância até o zero: |−7| = 7, |7| = 7 e |0| = 0
✅ O módulo como função por partes: x se x ≥ 0, −x se x < 0
✅ O gráfico em V de y = |x|, ponto a ponto
✅ Mover o V: em y = |x − 2| + 1, o vértice vai para (2, 1)
✅ Rebater: em y = |x² − 4|, a parte de baixo vira positiva
✅ O erro de levar o V para o lado errado
✅ O atalho: o vértice está onde o de dentro zera
