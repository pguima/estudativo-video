## Descrição
Dá para resolver o sistema 2x + y = 5 e x + y = 3 só com determinantes, sem somar nem substituir nada. Nesta aula, você escreve um sistema como multiplicação de matrizes, A · X = B, e resolve pela regra de Cramer: x = Dx/D e y = Dy/D. Vê também o mesmo sistema resolvido pela matriz inversa, o que acontece quando D dá zero e o erro de trocar a coluna errada. E ainda leva um atalho de prova: se a questão quer só uma letra, bastam dois determinantes. Serve para quem vai fazer a Unicamp e outros vestibulares.

📌 O que você vai aprender
✅ Escrever um sistema como A · X = B
✅ Conferir que A · X devolve o sistema, linha por coluna
✅ Os três determinantes da regra de Cramer: D, Dx e Dy
✅ x = Dx/D e y = Dy/D
✅ O mesmo sistema pela matriz inversa: X = A⁻¹ · B
✅ Por que Cramer não funciona com D = 0
✅ O erro de trocar a coluna errada e o atalho de uma letra só
