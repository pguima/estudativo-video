## Descrição
Olhando só para f(x) = x² − 4x + 3, dá para saber se o gráfico é um sorriso ou uma cara triste e onde ele cruza o eixo y. Nesta aula, você conhece a função quadrática, f(x) = ax² + bx + c com a diferente de zero, aponta a = 1, b = −4 e c = 3, monta a tabela de 0 a 4 (3, 0, −1, 0, 3) e vê nascer a parábola. Depois troca os sinais e vê a parábola virar de cabeça para baixo: a positivo abre para cima, a negativo abre para baixo. Por fim, descobre que a parábola corta o eixo y em (0, c), porque f(0) apaga tudo menos o c. Leva ainda um atalho de prova para desenhar a parábola em dois segundos. Serve para quem está voltando a estudar e para quem quer fechar a base antes de ENEM, Fuvest, Unicamp, Unesp e UERJ.

📌 O que você vai aprender
✅ O que é função quadrática: f(x) = ax² + bx + c, com a ≠ 0
✅ Apontar a, b e c com o sinal junto: em x² − 4x + 3, a = 1, b = −4, c = 3
✅ Da tabela à parábola: f(0) = 3, f(1) = 0, f(2) = −1, f(3) = 0, f(4) = 3
✅ Concavidade: a > 0 abre para cima, a < 0 abre para baixo
✅ Por que o a manda: longe do zero, o x² cresce muito mais rápido
✅ O corte no eixo y é o ponto (0, c)
✅ O erro de olhar o primeiro número escrito, como em 3 − x²
✅ O atalho: sinal do a e o c, e quando calcular f(0) direto
