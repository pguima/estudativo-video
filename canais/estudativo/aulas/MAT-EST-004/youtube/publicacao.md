## Descrição
Num gráfico de pizza, uma fatia vale 25%. Quantos graus ela tem? Quem responde 25° desenha uma fatia fininha: a resposta é 90°, o canto da folha. Nesta aula, você lê o gráfico de setores, passa de porcentagem para ângulo com a regra de três e faz o caminho de volta, de ângulo para porcentagem. No fim, leva um atalho de prova para fazer tudo de cabeça. Serve para quem está voltando a estudar e para quem quer fechar a base antes de ENEM, Fuvest, Unicamp, Unesp e UERJ.

📌 O que você vai aprender
✅ O gráfico de setores: o círculo inteiro é 100% e cada fatia é uma resposta
✅ Porcentagem para ângulo: a mesma porcentagem de 360° (25% = 1/4 = 90°)
✅ A regra de três: 100% está para 360° assim como 40% está para x (x = 144°)
✅ A pizza fecha: 144° + 90° + 72° + 54° = 360°
✅ Ângulo para porcentagem: a parte dividida por 360 (72/360 = 1/5 = 20%)
✅ O erro de usar o número de pessoas como porcentagem (8 pessoas não são 8%)
✅ O atalho: 10% = 36°, e quantos 36 cabem no ângulo
