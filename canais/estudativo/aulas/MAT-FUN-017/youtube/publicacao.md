## Descrição
Uma parábola corta o eixo x em dois pontos, outra só encosta nele e a terceira nem chega perto. Uma conta que você já conhece diz qual é qual antes de desenhar: o delta. Nesta aula, você vê que as raízes, ou zeros, são onde y = 0, resolve x² − 4x + 3 = 0 com Bhaskara (Δ = 4, x = 1 e x = 3) e desenha a parábola só com três pontos e a boca. Depois vê os três casos lado a lado: Δ > 0 corta em dois pontos, Δ = 0 encosta em um (x² − 4x + 4 encosta em (2, 0)) e Δ < 0 não toca (x² − 4x + 5 fica inteira acima do eixo). No fim, leva um atalho de prova, agora com o motivo visto no gráfico. Serve para quem está voltando a estudar e para quem quer fechar a base antes de ENEM, Fuvest, Unicamp, Unesp e UERJ.

📌 O que você vai aprender
✅ Raiz é onde a parábola toca o eixo x: faça f(x) = 0
✅ Achar as raízes de x² − 4x + 3 com Bhaskara: 1 e 3
✅ Desenhar a parábola com a boca, o corte no eixo y e as raízes
✅ Δ > 0 corta em dois pontos, Δ = 0 encosta, Δ < 0 não toca
✅ Com a negativo, os três casos de cabeça para baixo
✅ O erro de achar que, com Δ < 0, a parábola não existe
✅ O atalho: a e c com sinais contrários, corta em dois pontos sem conta
