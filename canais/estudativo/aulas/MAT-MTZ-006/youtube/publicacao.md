## Descrição
Três equações e três letras parecem muita coisa, mas o segredo é eliminar uma letra por vez até o sistema virar uma escada. Nesta aula, você resolve x + y + z = 6, x + 2y + z = 8 e x + y + 2z = 9 subtraindo equações inteiras, sobe a escada de baixo para cima e confere a solução (1, 2, 3). Vê também o que fazer quando é preciso multiplicar antes de subtrair, o erro de subtrair só o lado das letras e um atalho de prova para questões com alternativas. Serve para quem vai fazer Fuvest, Unicamp, UERJ e outros vestibulares.

📌 O que você vai aprender
✅ O que é um sistema 3x3 e o que é a solução (um trio)
✅ A escada: o sistema escalonado
✅ Tirar o x das outras equações, subtraindo equações inteiras
✅ Multiplicar antes de subtrair, quando precisa
✅ Subir a escada e conferir a solução
✅ O erro de subtrair só o lado das letras
