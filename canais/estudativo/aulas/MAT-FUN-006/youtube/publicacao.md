## Descrição
Um desenho no plano é o gráfico de uma função? Existe um teste que responde em segundos, só com uma régua em pé. Nesta aula, você monta a tabela de f(x) = x² − 1 de −2 até 2 (3, 0, −1, 0, 3), marca os cinco pontos, liga com uma curva suave e confere que f(0,5) = −0,75 cai em cima dela. Depois aprende o teste da reta vertical: se a régua em pé toca a curva duas vezes, não é função, como no círculo. No fim, leva um atalho de prova para montar a tabela mais rápido. Serve para quem está voltando a estudar e para quem quer fechar a base antes de ENEM, Fuvest, Unicamp, Unesp e UERJ.

📌 O que você vai aprender
✅ A entrada vai no eixo x, a saída no eixo y: cada par vira um ponto
✅ Tabela de f(x) = x² − 1: f(−2) = 3, f(−1) = 0, f(0) = −1, f(1) = 0, f(2) = 3
✅ Ligar os pontos com curva suave: f(0,5) = −0,75 cai na curva
✅ O teste da reta vertical: toca uma vez, é função; toca duas, não é
✅ O erro de passar a régua deitada: duas entradas com a mesma saída pode
✅ O atalho: em x² − 1, entradas opostas dão a mesma saída (não vale em x² + x)
