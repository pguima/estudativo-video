## Descrição
O intervalo fechado de 1 a 5, interseção com o intervalo aberto de 3 a 7. Muita gente responde [3, 5], fechado no 3, mas o 3 não pode entrar. Nesta aula, você empilha as retas com os números alinhados e acha [1, 5] ∩ ]3, 7[ = ]3, 5] e [1, 5] ∪ ]3, 7[ = [1, 7[, conferindo cada ponta. No fim, leva um atalho de prova para a interseção: o maior dos começos e o menor dos fins. Serve para quem está voltando a estudar e para quem quer fechar a base antes de Fuvest, Unicamp, Unesp e UERJ.

📌 O que você vai aprender
✅ Empilhar as retas com os números alinhados
✅ Interseção (e): onde ambas estão pintadas, [1, 5] ∩ ]3, 7[ = ]3, 5]
✅ União (ou): onde pelo menos uma está pintada, [1, 5] ∪ ]3, 7[ = [1, 7[
✅ Conferir as pontas: na interseção, basta uma reta deixar a ponta de fora para ela sair
✅ O atalho: maior começo e menor fim, e quando a interseção é o vazio
✅ Uma questão resolvida: [−2, 4[ ∩ [0, 6] = [0, 4[ e [−2, 4[ ∪ [0, 6] = [−2, 6]
