## Descrição
x² = 49 tem duas respostas: 7 e −7, porque (−7)² também dá 49. Nesta aula, você aprende a reconhecer a equação do 2º grau, ax² + bx + c = 0, a apontar os coeficientes a, b e c (em 2x² − 3x + 1 = 0, a = 2, b = −3 e c = 1) e a resolver as incompletas sem fórmula nenhuma. Sem b, isole o x²: x² − 49 = 0 dá x = 7 ou x = −7. Sem c, coloque o x em evidência: x² − 5x = 0 vira x(x − 5) = 0, e as raízes são 0 e 5. Você ainda vê por que dividir por x faz o zero sumir e leva um atalho de prova. Serve para ENEM, Fuvest, Unicamp, Unesp e UERJ, e para quem está voltando a estudar.
