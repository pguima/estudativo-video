## Descrição
Cinco questões inéditas, uma para cada ferramenta da trilha de polinômios. Em cada uma, pause o vídeo, resolva e depois confira a resolução passo a passo: polinômios idênticos, o valor de k para um polinômio ser divisível (teorema do resto), as raízes a partir de uma raiz dada (Briot-Ruffini e Bhaskara), a inequação (x + 2)²(x − 1) < 0 pelo sinal e a terceira raiz pelas relações de Girard. No fim, um atalho de prova: teste o 1 antes de qualquer conta. Serve para Fuvest, Unicamp e UERJ, e para quem está voltando a estudar.

📌 O que você vai praticar
✅ Identidade: a(x − 1)² + b ≡ 2x² − 4x + 5
✅ Teorema do resto: k para x³ + kx − 4 ser divisível por x − 2
✅ Raiz dada: Briot-Ruffini com −1 e Bhaskara no quociente
✅ Sinal: (x + 2)²(x − 1) < 0 com a raiz dupla
✅ Girard: duas raízes somam 3; qual é a terceira?
✅ O atalho: P(1) é a soma dos coeficientes
