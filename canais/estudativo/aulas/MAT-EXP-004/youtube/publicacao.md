## Descrição
Nove elevado a x dá 27? Testando, 9¹ dá 9 e 9² já passa para 81: nenhum número inteiro serve. Mesmo assim a resposta sai exata, em poucas linhas. Nesta aula, você aprende o método da equação exponencial: escreva os dois lados na mesma base, iguale os expoentes e resolva a equação que sobra. Você entende pelo gráfico por que dá para igualar os expoentes, resolve 2^(x+1) = 32, 9ˣ = 27 e 2ˣ = 1/8 e leva um atalho de prova: fatorar até o primo. Serve para quem está voltando a estudar e para ENEM, Fuvest, Unicamp, Unesp e UERJ.

📌 O que você vai aprender
✅ A ideia: 2ˣ = 32 vira 2ˣ = 2⁵, e x = 5
✅ Por que funciona: a curva sempre sobe, cada saída vem de uma entrada só
✅ O método em três passos: mesma base, expoentes iguais, resolva
✅ 2^(x+1) = 32: x + 1 = 5, então x = 4
✅ 9ˣ = 27: base 3, 3^(2x) = 3³, x = 3/2
✅ Quando o outro lado é fração: 2ˣ = 1/8 dá x = −3
✅ O erro de dividir 27 por 9
✅ O atalho: fatore até o primo para achar a base
