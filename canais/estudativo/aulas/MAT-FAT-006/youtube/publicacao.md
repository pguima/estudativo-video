## Descrição
Cinco questões inéditas, uma para cada ferramenta desta parte do curso: abrir (2x − 3)² sem multiplicar tudo, fatorar x³ − 4x até o fim, calcular (x² + 10x + 25)/(x + 5) para x = 95 sem conta grande, racionalizar 6/(√5 − √2) e calcular 1.002 · 998 de cabeça. Em cada uma, pause o vídeo, resolva e só depois veja a resposta, com o teste do 10 para conferir. Serve para ENEM, Fuvest, Unicamp, Unesp e UERJ, e para quem está voltando a estudar.

📌 O que você vai praticar
✅ (2x − 3)² = 4x² − 12x + 9, e o erro de esquecer de elevar o 2
✅ x³ − 4x = x(x + 2)(x − 2): fator comum antes de tudo
✅ (x² + 10x + 25)/(x + 5) = x + 5: com x = 95, dá 100
✅ O atalho: simplifique antes de trocar o x
✅ 6/(√5 − √2) = 2(√5 + √2), pelo conjugado
✅ 1.002 · 998 = 1.000² − 2² = 999.996
