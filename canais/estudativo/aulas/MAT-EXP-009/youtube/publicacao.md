## Descrição
O logaritmo de 8 na base 2 dá 3, o de 4 dá 2, e o de 32, que é 8 vezes 4, dá 5: três mais dois. Os números se multiplicaram e os logaritmos se somaram. Nesta aula, você entende por que isso acontece escrevendo tudo como potência de 2 e aprende as três propriedades: log(a · b) = log a + log b, log(a/b) = log a − log b e log aⁿ = n · log a. Depois desmonta log 12 em 2 · log 2 + log 3, vê o erro de separar o logaritmo de uma soma e leva um atalho de prova para a base 10: os zeros saem somando. Serve para quem está voltando a estudar e para ENEM, Fuvest, Unicamp, Unesp e UERJ.

📌 O que você vai aprender
✅ Por que log₂ 32 = log₂ 8 + log₂ 4: 2³ · 2² = 2⁵
✅ Produto: log(a · b) = log a + log b, todos na mesma base
✅ Divisão: log(a/b) = log a − log b, o de cima menos o de baixo
✅ Potência: log aⁿ = n · log a, e log₂ 4³ = 3 · 2 = 6
✅ Desmontar: log 12 = 2 · log 2 + log 3
✅ O erro: log₂(4 + 4) não é log₂ 4 + log₂ 4
✅ O atalho: log 3.000 = log 3 + 3
