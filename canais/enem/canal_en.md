# Estudativo English: channel description and tags

English version of **Estudativo**, focused on **Math** (lessons and solved questions). Decided on 2026-10-25, to grow the
Estudativo brand instead of opening a separate math channel. Not every Estudativo video gets an English version: ENEM
does not exist in the US (an SAT series is a future project), so only math that makes sense outside the ENEM is translated.
Each English video is the same project rendered with `--lang en` (`roteiro/cenas_en.py`, `audio_en/`, `youtube_en/`,
`final/*_en.mp4`). Same math design system as the Portuguese videos (`_ferramentas/matematica.py`).

Where to paste: YouTube Studio → Customization → Basic info (description) and Settings → Channel → Basic info (keywords).
Suggested handle: **@EstudativoEnglish** (check availability; alternative @EstudativoEN).

## Channel description (up to 1,000 characters)
```
Estudativo English: math explained like a real lesson, step by step, from scratch.

Every video takes one idea — or one tricky question — and explains every tool it uses by name: where the formula comes from, a number example, and then the solution. No skipped steps, no "just memorize it".

🎯 What you'll find here:
• Solved math questions, explained like a lesson
• Full lessons: algebra, geometry, functions, arithmetic
• Visual explanations with on-screen captions
• Challenges in the comments to practice what you learned

💬 Got the challenge right? Tell me in the comments. Have a question you want solved? Send it — it might become a video.
🎙️ Narration uses a synthetic (AI) voice.

🇧🇷 Prefer Portuguese? Watch on Estudativo: <link do canal Estudativo>
```
